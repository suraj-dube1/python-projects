# ATM Banking System

A beginner-level Python project that simulates the basic structure of an ATM banking system.

## Overview

This project is currently focused on building the basic ATM structure using **Python classes, variables, and menu-driven operations**.

The current version includes the initial setup for managing a bank account, including balance and PIN, along with a menu for basic ATM operations.

## Current Features

- ATM class structure
- Basic account balance
- PIN setup
- Menu for ATM operations
- Initial deposit, withdrawal, and balance-checking structure

## Technology

- **Python**
